# DropLens — Commercial & Deployment Guide

DropLens is released under the **MIT License**, so you are free to:

- use it internally at any scale,
- redistribute `DropLens.exe` to customers/employees,
- fork and sell your own branded, closed-source product (including the build
  script, engine and UI — MIT permits sublicensing under other terms).

The only requirement MIT imposes: keep the copyright notice in any
substantial copy of the software or source.

## Recommended release pipeline (quality / trust)

1. **Pin dependencies** — commit a frozen `requirements.txt` (e.g.
   `pip freeze > requirements-lock.txt`) and build from a **clean virtualenv** so
   every binary is reproducible.
2. **Build + smoke test** — `powershell -ExecutionPolicy Bypass -File .\build.ps1`
   already compiles all sources and runs `tests\test_engine.py` before the
   PyInstaller pass.
3. **Code-sign the exe** — distribution without a signature triggers SmartScreen
   warnings. Standard: an **OV/EV code-signing certificate** (Sectigo, DigiCert,
   Microsoft trusted partners), e.g.
   `signtool sign /fd SHA256 /a dist\DropLens.exe`.
4. **Version metadata** — bump `build\version_info.txt`, add a CHANGELOG entry,
   tag the release.
5. **Publish to GitHub Releases** — attach `dist\DropLens.exe`
   (`gh release create v1.0.0 dist/DropLens.exe — title/notes`), keep
   `Source code (.zip/.tar.gz)` autogenerated.

## Optional Tesseract OCR (image text extraction)

Tesseract is *not bundled* (license/install-footprint reasons). DropLens
auto-detects it in standard install locations or lets users point at it in
Settings. For enterprise deployment use silent install:

```powershell
# example silent install for OCR support on user machines
.\tesseract-ocr-w64-setup-*.exe /S
```

Users without it still get name/size/meta indexing for images (status shows
`ocr_unavailable` with a hint).

## Translation dependency note

Translation uses Google’s public translation endpoint (no API key). It is
calls-on-demand and cached. If you need SLA/volume guarantees, swap
`engine/translate.py` for DeepL/Azure/Google-Cloud with an API key — the rest of
the app is unaffected.

## Support model suggestions

- Keep user data location documented (`%LOCALAPPDATA%\DropLens`) — rotate off the
  `droplens.log` for support tickets.
- Export features (catalogue CSV, results CSV, translation TXT) give you an easy
  migration/audit story for enterprise buyers.
